# 五行语宙

## 一、🌿 简介

“五行语宙”是一站式中医智能教育网站，围绕五行理论与中医文化设计了微课学习、知识科普、互动游戏、AI 对话、社区分享和智能舌诊等模块。项目以静态网页形式组织，适合用于课程展示、文化传播、学习体验演示和前端作品展示。

## 二、✨ 功能介绍

- **智课星链**：提供中医与五行主题微课程，包含五行相生相克、五行音乐疗法、黄帝内经共读、AI 健身教学等内容。
- **智识中医**：展示中医基础知识、中药材、人体五脏、诊疗方法、发展历史、名医名篇和五行知识。
- **时珍智脑**：以李时珍为角色进行中医知识问答，营造沉浸式学习体验。
- **五行智弈**：提供“五行归类大挑战”等互动游戏，通过分类、答题等方式巩固中医知识。
- **智联杏林**：模拟中医文化交流社区，展示话题、投票、分享和用户讨论内容。
- **智能舌诊**：支持上传舌部照片并调用舌诊分析接口，展示舌象特征、体质分析、风险提示和调养建议。

## 三、🚀 使用方法

本项目是静态网站，无需安装依赖或执行构建命令。

0.直接访问：
https://aiwuxing.maozi.io


1. 克隆仓库：

```bash
git clone https://github.com/m4rklee/aiwuxing.git
cd aiwuxing
```

2. 启动本地静态服务：

```bash
python3 -m http.server 8080
```

3. 在浏览器中打开：

```text
http://127.0.0.1:8080
```

也可以直接打开 `index.html` 预览页面，但建议使用本地静态服务访问，以便视频、图片、iframe 和跨页面资源路径表现更稳定。
